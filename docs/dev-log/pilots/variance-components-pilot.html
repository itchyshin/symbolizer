PILOT — “Variance components speak biology”

Review artifact, not shipped. This page lives in docs/dev-log/pilots/ (never in docs/articles/), changes nothing in the package, and is here only so you can see what the surface looks like and how it would integrate before approving. Numbers are from a real lmer fit. Prose shown is what the new inst/extdata/variance-readings.csv would hold (templated, not string-spliced in R).
The model: boldness scored 4× on each of 30 lizards, boldness ~ assay_temp + (1 | lizard). A biologist fitting this wants one thing above all: how repeatable is boldness? — i.e. how much of the variation is between lizards vs within.

Where does the variation live?

between inds 63.9%

Of the total variation in boldness, about 63.9% sits between inds and about 36.1% within them.

3. Proposed: ICC / repeatability line

Repeatability (ICC) = 0.639. Two boldness scores from the same ind are correlated about this strongly; inds account for 63.9% of the variation. (Single random intercept, Gaussian — the case where this is a true proportion of variance.)

Formula shown to the reader on hover/caption: $R = \dfrac{\sigma^2_{\mathrm{ind}}}{\sigma^2_{\mathrm{ind}} + \sigma^2_{\varepsilon}} = \dfrac{1.15}{ 1.8} = 0.639$

4. Proposed: prose-only shrinkage caption (beside the worked-row BLUP)

Each û(ind) is partially pooled: the model nudged it toward the overall mean rather than using the raw ind mean — inds with fewer or noisier observations are pulled harder. That borrowing of strength is what (1|ind) does.

Prose only — no new numbers. Numeric shrinkage % deferred (unstable near zero; honest only for Gaussian intercept-only).

6. Honesty contract (the guardrails)
  • Gaussian-identity only for the % and ICC. This fit qualifies (gaussian + single random intercept ✓).
  • For a GLMM (Poisson/binomial), the data-scale % is refused — there is no residual variance on the data scale, so the percentage would be meaningless. The table still shows; the bar does not.
  • Every reading carries a point-estimate-only caveat and reuses the existing few_re_levels / few_groups_wald warnings.
  • All prose comes from variance-readings.csv — none string-spliced in R.
