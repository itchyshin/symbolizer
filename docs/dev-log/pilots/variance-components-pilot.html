Of the total variation in boldness, about 63.9% sits between lizards and about 36.1% within them.

ICC line

ICC = 0.639. Lizards account for 63.9% of the variation; two boldness scores from the same lizard are correlated about this strongly. (In a single-random-intercept Gaussian design the ICC is the repeatability.)

$\mathrm{ICC} = \dfrac{\sigma^2_{\mathrm{lizard}}}{\sigma^2_{\mathrm{lizard}} + \sigma^2_{\varepsilon}} = \dfrac{1.15}{ 1.8} = 0.639$ — a true proportion of variance because the Gaussian residual is on the same (data) scale.

Each û(lizard) is partially pooled — nudged toward the overall mean; lizards with fewer/noisier scores pulled harder. That borrowing of strength is what (1|lizard) does. (prose only; numeric shrinkage deferred)

B. Binomial random intercept — latent-scale ICC (NEW: feasible now)

nestling survival (0/1), 6 chicks in each of 40 nests: surv ~ temp + (1 | nest), logit link.
componentvariance (logit scale)SD
between nests1.251.12
latent residual (fixed: π²/3)3.291.81

Latent-scale ICC (logit link)

between nests 27.5%
latent residual (π²/3) 72.5%
Latent-scale ICC = 0.275 (logit scale). On the unobserved logit scale, nests account for 27.5% of the variation. The residual variance on this scale is the known logistic constant $\pi^2/3 \approx 3.29$ (it would be $1$ for a probit link → ICC = 0.556). This is NOT a proportion of variance in the observed 0/1 survival — a Bernoulli response has no single data-scale residual variance, so only the latent-scale reading is honest here.

$\mathrm{ICC}_{\mathrm{latent}} = \dfrac{\sigma^2_{\mathrm{nest}}}{\sigma^2_{\mathrm{nest}} + \pi^2/3} = \dfrac{1.25}{4.54} = 0.275$

D. Honesty contract
  • Gaussian-identity single random intercept → data-scale ICC & % (a true variance proportion). ✓
  • Binomial (logit/probit) → latent-scale ICC with the fixed residual ($\pi^2/3$ or $1$), always explicitly labelled “latent scale, not a proportion of observed-outcome variance.” ✓ (this v2)
  • Poisson / other GLMMs → deferred (need the log-normal / trigamma distribution-specific variance). Table shows; ICC line withheld with a one-line “not yet on this scale” note. —
