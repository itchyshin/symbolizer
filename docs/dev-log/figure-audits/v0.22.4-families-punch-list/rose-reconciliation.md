Per the architectural rule, prose/templates live in CSV.
**RED test:** In tests: read inst/extdata/family-distributions.csv; expect grepl('Beta\\(\\\\boldsymbol\\{\\mu\\},', matrix_col[family=='beta']) to be FALSE and grepl('1 - \\\\boldsymbol\\{\\mu\\}', matrix_col[family=='beta']) to be TRUE. Or snapshot the rendered Tab 2 Beta line.
