The package extracts the payoff of a mixed model and then drops it on the floor. ARCHITECTURE: every shortlist item fits the constraints because the proven template already exists — R/marginal-estimates.R demonstrates the exact safe pattern (S3 generic + .symbolized_model method, marg_check_family_supported() family gate, metadata$fit retrieval, classed honest-print tibble with a lognormal scale special-case at line 110), and the few_re_levels/few_groups_wald warnings (R/warnings.R:40, R/symbolize-lme4.R:413-421) are ready to gate small-n cases. ## Avoid (honesty hazards)
- Naive data-scale ICC / repeatability / variance-partition % for non-Gaussian GLMMs. For Poisson/binomial there is no residual variance on the data scale, so sigma2_g/(sigma2_g+sigma2_resid) is meaningless. The ONLY honest options are (a) Gaussian-identity-only in v1, or (b) an explicitly labelled latent-scale ICC using a distributional-variance constant (pi^2/3 for logit) with a mandatory 'NOT a proportion of variance in observed Y' clause. Printing a clean Gaussian-style percentage for a GLMM is the central honesty hazard the whole brainstorm flags — do not ship it.
- The data-vs-model goodness-of-fit / sanity panel (Field-ecologist P4: observed-vs-implied zero fraction, var/mean). VISION explicitly says symbolizer is NOT a peer-review/GOF oracle; this edges into model criticism, is L-effort and the highest-risk single idea, needs per-row mu that isn't cheaply available for every class, and would invite 'is my model good?' expectations the package deliberately refuses. Point users to DHARMa instead.
- Overdispersion 'verdict' with thresholds (Fisher P4) as an early slice. The Pearson-phi estimator's residual df is genuinely fuzzy with random effects, it is meaningless for free-dispersion families (nbinom2, Gaussian, Beta) and must be SUPPRESSED there (not relabelled), and a bucketed verdict drifts toward the hypothesis-testing culture VISION avoids. Defer until the variance engine is solid; if ever shipped, coarse 3-bucket 'rough check' wording only, Poisson/Bernoulli only.
- Numeric shrinkage claims ('pulled 60%') or raw-mean-vs-BLUP comparisons as a first slice (the quantitative halves of Pat P3 / Darwin P4 / Fisher P5 / Noether P4). The simple 1 - BLUP/raw formula is unstable near zero, the 'raw group mean' is only unambiguous for intercept-only (1|group) fits (with covariates the comparison is to a conditional mean and misleads), and it is exact only for Gaussian. Ship the prose-only caption (shortlist #5); gate any number behind the closed-form factor + Gaussian-intercept-only.
- Reference-level / grouping-role strips that assume the coding (Pat P5, Darwin P5). 'Differences measured from the reference' is FALSE under sum-to-zero/Helmert contrasts; a count-based 'subjects vs blocks vs observation-level' tag cannot distinguish an observation-level RE from a genuine many-small-groups design. Worthwhile only if rendered solely for unambiguous signatures (treatment/dummy contrasts; n_levels==n_obs) and silent otherwise — never a guessed verdict.
- Any uncertainty footer or '*'-explainer that promises information the surface does not actually show (Pat P6). Because most surfaces show no CI yet, a footer describing a 95% interval is dishonest where no interval is rendered. Only assert what is displayed; omit the marker sentence on surfaces with no interval rather than imply one exists.
- Auto-narration / variance numbers folded into Methods text ON BY DEFAULT (Field-ecologist P3). Useful but must stay opt-in (methods_text(sym, include_vc=TRUE)) per the VISION rule that auto-narration is never the default, and must surface the few_groups_wald caveat and a 'add the CI from confint(profile)' reminder — an SD point estimate dropped into a Methods sentence reads as more precise than it is.
