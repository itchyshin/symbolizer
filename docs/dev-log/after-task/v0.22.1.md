### v0.22.1.1 (V2 Pat blocker rollup)

V2 Pat-lens flagged the article's central thesis equation
($\mathbf{u}_p \sim \mathcal{N}(\mathbf{0}, \sigma_p^2\,\mathbf{A})$)
was missing from the rendered widget. Root cause: drmTMB consumes
`phylo()` into its internal sparse-precision pipeline, so
`fit$random_effects` never carries the phylo tier and the equation
renderer never saw it.

- `symbolize.drmTMB()` now synthesises a random-effect row for each
  `phylo()` / `animal()` marker. The detection runs upstream of the
  `re_tbl` / `variance_components` / `components` builds, so all
  downstream consumers see the structured tier.
- `drm_build_components()` receives `structured_matrix_for_group`
  and emits $\mathbf{u}_g \sim \mathcal{N}(\mathbf{0},\,
  \sigma_g^2\,\mathbf{A}_{k \times k})$ for any structured tier
  instead of falling through to $\mathbf{I}_n$.
- The linear-predictor matrix form disambiguates multiple
  intercept-only groups (single-RE keeps bare $\mathbf{u}$;
  multi-RE emits $\mathbf{u}_{g_1} + \mathbf{u}_{g_2}$). Without
  this, the equation was emitting $\mathbf{X}\boldsymbol{\beta} +
  \mathbf{u} + \mathbf{u}$, which is unreadable.
- `sym$metadata$structured_matrices` is now populated for
  consumers that want to introspect the structured tier.
- §4.3 prose adds a one-sentence model description before the
  syntax-heavy intro (V2 Flow break 3).
- §4.5 prose labels the `$sigma2` rows and adds a one-sentence
  biological reading (study variance dominates phylo variance on
  this dataset). Heritability formula appended (V2 Flow break 4).

## Lesson recorded

A V-agent blocker that names "feature X is missing from rendered
output" without a code-side root cause is often a missed propagation
through one of `re_per_entry` / `structured_matrix_for_group` /
`metadata`. When the extractor logs the detection (`phylo` in
`detected_signals`, `phylo_representation = "all_nodes"`) but the
renderer doesn't show the feature, look for an integration seam
that wasn't wired through. Three lines in `symbolize.drmTMB()` plus
a one-line argument pass to `drm_build_components()` resolved a
blocker that would otherwise have hardened into a deferred slice.
