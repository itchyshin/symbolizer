# symbolizer: Symbolic Specifications, Interpretations, and Teachable Stories for Statistical Models

Turns fitted distributional, multivariate, latent-variable, spatial,
mixed-effect, meta-analytic, and additive models into structured
symbolic specifications that render as publication-ready LaTeX
equations, assumption tables, formula bridges, parameter
interpretations, structural model comparisons, methods-section
paragraphs, and structural DAGs. First-class methods for 'drmTMB',
'gllvmTMB', 'glmmTMB', 'brms', 'lme4', 'MCMCglmm', 'sdmTMB', 'stats::lm'
/ 'stats::glm', 'metafor', and 'mgcv'. Complementary to 'equatiomatic'
for one-formula models.
