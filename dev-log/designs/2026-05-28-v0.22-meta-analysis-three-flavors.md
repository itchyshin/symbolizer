## 1. Why an expanded scope

The maintainer's overnight message (verbatim): "Once you've finished the gllvm stuff, you can start to meta-analyst stuff if you like overnight … we want to do traditional meta-analysis, phylogenetic meta-analysis, location-scale meta-analysis, all that kind of stuff." Earlier in the same conversation: "We want to actually use meta for glmmTMB and drmTMB."

That's three flavors × three packages = nine cells. Not every cell is structurally distinct (some collapse to the same math via different syntax), but every cell has educational value: a meta-analyst familiar with one of the three packages should be able to find their entry point.

**Three flavors of meta-analysis (named-concept intro the article opens with):**

1. **Traditional meta-analysis** — pool $K$ study-level effect sizes $y_k$ with known sampling variances $v_k$:
   $$y_k \mid \theta_k \sim \mathcal{N}(\theta_k, v_k), \quad \theta_k \sim \mathcal{N}(\mu, \tau^2).$$
   The headline parameter is $\tau^2$ (between-study heterogeneity).

2. **Phylogenetic meta-analysis** — when studies are on related species, the between-study tier becomes structured by phylogeny:
   $$\theta_k = \mu + u_{p,k} + u_{s,k}, \quad u_p \sim \mathcal{N}(\mathbf{0}, \sigma_p^2 \mathbf{A}), \quad u_s \sim \mathcal{N}(\mathbf{0}, \sigma_s^2 \mathbf{I}).$$
   See `2026-05-27-v0.22-meta-and-gllvm-widget.md` for the deep dive (Cinar et al. 2022; Mizuno et al. 2026 frameworks).

3. **Location-scale meta-analysis** — model the between-study variance itself as a function of moderators:
   $$y_k \sim \mathcal{N}(\mu(x_k), v_k + \tau^2(x_k)), \quad \log \tau(x_k) = \gamma_0 + \gamma_1 x_k.$$
   The headline question: do moderators predict *heterogeneity*, not just the mean? Distributional regression on the variance side.

## 3. Per-flavor scope

### §3 — Traditional meta-analysis

**The model.** Random-effects pooling:

$$y_k \mid \theta_k \sim \mathcal{N}(\theta_k, v_k), \qquad \theta_k \sim \mathcal{N}(\mu, \tau^2), \qquad k = 1, \ldots, K.$$

Both $v_k$ (known sampling variance per study) and $\tau^2$ (estimated between-study heterogeneity) must be modeled. Naive ANOVA treats $\tau^2$ as the only residual; modern meta-analysis treats $v_k$ as a fixed offset.

**Three Faces.**

| Face | Package | Call | Widget? |
|---|---|---|---|
| 1 (deep) | `metafor` | `rma(yi, vi)` or `rma.mv(yi, V = vi, random = ~ 1 \| study)` | Three-views + PDF |
| 2 (light) | `glmmTMB` | `glmmTMB(yi ~ 1 + (1 \| study), dispformula = ~0, weights = 1/vi)` (with the known-vi bridge wired through `weights`) | Code + tables |
| 3 (light) | `drmTMB` | `drmTMB(yi ~ 1, weights = 1/vi)` (residual SD on the trait scale; weighted-LS interpretation) | Code + tables |

The bridge: each package surfaces $\tau^2$ from a different parameter slot.

- `metafor::rma()$tau2` directly.
- `glmmTMB`: `VarCorr(fit)$cond$study[1]` (the random-intercept variance).
- `drmTMB`: residual SD `fit$report$sigma_eps` — interpretation differs (no $v_k$ tier, so $\sigma_\varepsilon^2$ absorbs both sampling and heterogeneity).

### §4 — Phylogenetic meta-analysis

Per the 2026-05-27 design. Three Faces: `metafor::rma.mv` deep (widget), `brms::brm` with `se(sqrt(vi))` + `gr(species, cov = A)` (light), `MCMCglmm` with `ginverse` + `mev` (light).

**Extractor work required** (deferred from 2026-05-27):
- `symbolize.brms` learns the `se(sqrt(vi))` meta-analytic bridge.
- `symbolize.MCMCglmm` learns the `mev = vi` measurement-error-variance bridge.
- Both are small additions to existing extractors.

### §5 — Location-scale meta-analysis

**The model.** Distributional regression on the variance side:

$$y_k \sim \mathcal{N}(\mu_k, v_k + \tau_k^2), \qquad \mu_k = \beta_0 + \beta_1 x_k, \qquad \log \tau_k = \gamma_0 + \gamma_1 x_k.$$

The moderator $x_k$ shifts both the mean and the heterogeneity. Useful for moderators where the *spread* of effects is biologically meaningful (e.g., study-design quality predicts τ; sample-size predicts τ via small-study effects; species-trait predicts τ).

**Three Faces.**

| Face | Package | Call | Widget? |
|---|---|---|---|
| 1 (deep) | `drmTMB` | `drmTMB(drm_formula(yi ~ x, sigma ~ x + offset(0.5*log(vi))), family = gaussian())` | Three-views + PDF |
| 2 (light) | `glmmTMB` | `glmmTMB(yi ~ x, dispformula = ~ x, weights = 1/vi)` | Code + tables |
| 3 (light) | `metafor` | `rma.mv(yi, V = vi, mods = ~ x, scale = ~ x)` (if metafor supports scale-modelling at the time of write; otherwise drop and replace with brms `bf(yi ~ x, sigma ~ x)`) | Code + tables |

The `offset(0.5*log(vi))` term in the drmTMB σ-submodel is a known trick for meta-analysis: it pins the σ scale so the implied total variance is $v_k + \tau_k^2$ rather than just $\tau_k^2$. **Verification item P1 for this slice**: confirm drmTMB accepts this offset syntax in the σ-submodel.

## 5. Article-wide pedagogical principles

Mirrored from the gllvm rewrite (Nakagawa et al. framework + lavaan / rstanarm / gllvmTMB pedagogy survey):

- **Named concept before symbol.** "Traditional pooling" before $\tau^2$; "phylogenetic heterogeneity" before $\sigma_p^2$; "moderator-driven dispersion" before $\gamma_1$.
- **One dataset per flavor, watch numbers migrate across packages.** Traditional: synthetic + reported $y_k, v_k$ from a public meta-dataset (Lipsey & Wilson 2001 example, or one of the metafor built-ins like `dat.bcg`). Phylo: reuse Moura 60-species (from 2026-05-27 design). Location-scale: synthesize with a known moderator dependence so the article can show the recovery.
- **Single anchor equation reused everywhere.** The general form $y_k \sim \mathcal{N}(\mu_k, v_k + \tau_k^2)$ with each flavor specifying $\mu_k$ and $\tau_k^2$.
- **Defaults made explicit.** Document what each package silently fixes: metafor's REML default; glmmTMB's `dispformula = ~0` vs leaving it free; drmTMB's `family = gaussian()` default; brms's `se()` semantics; MCMCglmm's `mev` semantics.
- **Cross-package equivalence table.** §7 carries a table mapping the same math across packages — like the `gllvmTMB ↔ glmmTMB` bridge in the gllvm article.

## 7. Out of scope (explicit non-goals)

- **Multivariate meta-analysis** (`rma.mv` with `struct = "UN"` or "CS" on multiple outcomes). Already covered for `metafor` in the existing `vignettes/symbolizer-meta.Rmd`. Leave for a later slice if user asks.
- **Spatial meta-analysis** (Mizuno et al. 2026 phylo+spatial). Separate future article.
- **Publication-bias / selection models** (Egger, PET-PEESE, RoBMA, copas). Out of symbolizer's symbolic surface entirely.
- **Bayesian model averaging across heterogeneity priors.** Conceptually meta, mechanically Bayesian; out of scope.
- **Meta-regression with non-linear or GAM-style moderators.** Out of scope for this slice; can be a future extension.
